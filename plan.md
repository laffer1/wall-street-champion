# Wall Street Champion — plan.md

A stock-trading game written in Rust, rendered with Vulkan and an FSR 1.x
(FidelityFX Super Resolution) upsampling pass. Targets Linux, FreeBSD and
MidnightBSD (any Unix with a Vulkan driver and X11/Wayland; also fully
playable headless in a terminal).

## Premise

You inherit **$100,000** (sudden windfall). You have **six months (26 weeks)**
to grow it to **$1,000,000**. Succeed and a trading firm hires you; fail and
you are penniless. You have no other income: **living expenses of $1,500 are
deducted from your account every week**.

## Markets (all symbols are invented)

- 12 fake stocks across sectors (tech, finance, energy, biotech, retail,
  industrials, consumer, logistics...)
- 3 fake ETFs (broad index, clean energy, precious metals) + 2 fake **crypto
  ETFs** (crypto basket, blockchain)
- 6 fake **crypto coins** with simulated prices (much higher volatility)

## Simulation (weekly ticks, grounded in real market history)

Parameters are modeled on long-run real-world statistics (see
`src/sim/market.rs` comments): e.g. S&P 500 annualized volatility ~16%
=> ~2.2% weekly; crypto weekly volatility 10–25%; earnings moves of ±5–15%;
quarterly dividends; bull/bear/sideways regimes with drift/vol per regime;
volatility clustering; margin interest ~ market broker rates.

Each week (`end_week`):

1. Market regime transition (Markov chain: bull / sideways / bear).
2. Index + sector factor returns, then per-instrument idiosyncratic returns
   (beta to index, sector beta, own volatility, momentum for crypto).
3. **Quarterly earnings reports** in weeks 6, 13, 19, 26 — EPS surprise moves
   the price and generates news.
4. **Dividends** for dividend-paying stocks on the same quarterly weeks.
5. Random events: macro (central-bank decision, oil shock, geopolitical),
   sector, company (product launch, scandal, guidance), crypto (exchange
   hack, ETF inflow, influencer tweet). Events add a price impulse and news.
6. Living expenses ($1,500) and margin interest (0.5%/week on debt) are
   charged. Net worth <= $0 means bankruptcy (game over, penniless).

## Trading rules

- You may trade **once per week**: queue any number of BUY/SELL orders, then
  press **End Week** — all orders fill at that week's close, then the market
  advances one week.
- **Margin**: buying power = cash + up to 1x your equity (2x leverage),
  interest 0.5%/week on the borrowed amount.
- Win check after week 26: net worth >= $1,000,000 => hired by a trading firm.

## News, newspaper, TV

Every week the game generates financial news. Two outlets with different
flavors: the newspaper ("The Daily Bull & Bear", more factual) and the TV
channel ("MONEY-TV 24", more sensational/hype). Headlines **hint** at next
week's direction (sentiment correlates with the coming return, with noise).

**AI option:** if a local model server is reachable (Ollama HTTP API on
`127.0.0.1:11434`, model via `WSC_MODEL`, default `llama3.1:latest`), headline
bodies are generated by the local model (runs on GPU when available, CPU
otherwise). Otherwise — or on any LLM error/timeout — the game falls back to
its procedural template generator. Enable/disable at runtime with the `L` key
or `--llm` / `WSC_LLM=1`. No cloud API is ever contacted.

## Tipsters

8 generated people (bartender, analyst, retired trader, influencer, cab
driver...) each have a hidden reliability in [35%, 90%]. Each week 2–4 of them
offer a tip ("NBLD is about to moon" / "dump VLC"). You can follow a tip
(invests 10% of equity in that direction) or ignore it, and mark tipsters as
trusted/untrusted. At the end you see who was actually right.

## Rendering (Vulkan + FSR 1.x)

- `ash` (dynamically loads `libvulkan.so.1` at runtime — works on
  Linux/FreeBSD/MidnightBSD), `winit` window (X11/Wayland), or a headless
  surface (`VK_EXT_headless_surface`) for `--gpu-headless` runs/screenshots.
- Scene is drawn into a low-resolution offscreen image (colored quads +
  bitmap-font text — vendored public-domain 8x8 font), then:
  - **FSR 1.x ON**: an **EASU** compute pass (edge-adaptive spatial upsampling,
    12-tap Lanczos-style kernel — ported from AMD's FidelityFX-FSR reference
    `ffx_fsr1.h`) upscales to full resolution, followed by an **RCAS** pass
    (robust contrast-adaptive sharpening). Render scale default 0.66x.
  - FSR OFF: direct present of the offscreen image.
  - Toggle with the `F` key. Shaders are WGSL compiled to SPIR-V at runtime by
    `naga` (pure Rust — no shader toolchain needed at build time on any OS).
- UI: top bar (week, cash, equity, goal progress), portfolio panel, price
  chart, newspaper + TV panels, tips row, and a scrolling **fake stock ticker
  along the bottom** with all symbols, prices and weekly changes.

## Modes

- `wall-street-champion` — Vulkan window (needs display + Vulkan GPU).
- `--gpu-headless --frames N --screenshot out.png` — renders N frames on a
  headless Vulkan surface (no X needed; works with lavapipe or a real GPU)
  and writes a PNG. Used for automated verification.
- `--headless [--bot]` — full game in the terminal; `--bot` plays 26 weeks
  automatically (verification / demo).
- `--seed N` — deterministic market; `--llm` — enable local-model news.

## Build & run (Linux / FreeBSD / MidnightBSD)

```
cargo build --release
./target/release/wall-street-champion            # Vulkan window
./target/release/wall-street-champion --headless # terminal
```

Runtime needs: a Vulkan driver (`libvulkan.so.1`; Mesa RADV on AMD GPUs, or
lavapipe/llvmpipe for software rendering — all packaged on Linux, FreeBSD and
MidnightBSD) and X11/Wayland for windowed mode. `cargo test` needs nothing.
The Vulkan loader is dlopen'ed at runtime (`ash` "loaded" feature), so the
binary does not link against libvulkan at build time and builds identically on
all three OSes. Ollama, when used for AI news, also runs on FreeBSD and
MidnightBSD and can use Vulkan there (`ollama serve`, models via
`ollama pull llama3.1`).

## Verification (performed on this machine: AMD Radeon RX 9060 XT, RADV)

- `cargo test` — 10 integration tests pass (determinism, 26-week termination,
  margin rule, dividends, news/tips, win/bankrupt paths).
- `--headless --bot` — full auto-played games across many seeds; ~50% of seeds
  reach $1M with a simple sentiment strategy (good difficulty for a 10x goal).
- `--gpu-headless --frames 24 --screenshot out.png` on the RX 9060 XT (RADV)
  with FSR 1.x on (845x475 -> 1280x720 via EASU+RCAS) and off — PNGs verified
  visually: top bar, portfolio, charts, newspaper/TV panels, tips, and the
  scrolling ticker at the bottom all render correctly.
- Same headless run on lavapipe (llvmpipe software Vulkan) initializes and
  renders, so the game also works with no GPU at all.
- `--llm` against a local Ollama server (llama3.1) — news bodies are written
  by the local model; with no server running the game falls back to
  procedural headlines (verified both paths).
